# APEX 11 · Race39

默认 20 圈，可选 3—30 圈，11 队 22 车，24 站。加入预测避让、并排留空间、部件维修与按总圈数划分的收官阶段。继承 Regulations33 比赛规则，车队资金管理包含赛前燃油、双车维护、轮胎、维修、升级五类支出。

每队初始 500 万虚拟资金；奖金、赞助、各项支出和升级投入照常结算。各车队的“资金与经营”面板仅展示资金概况（含本季已付金额）、策略、升级状态与费用说明，不列奖金表或账单明细。

- 正赛禁补油，发车预算覆盖本站全程；两次基础停靠（短程按圈数一次），另有一次普通可选停靠。
- 软/中/硬各两套、半雨三套、全雨两套；旧胎保留磨损，干地至少使用两种配方。
- 动态维修预约、按部件工时维修，20% 损伤开始评估；天气和危险车况独立服务。
- 检测点一秒内获得下一圈超车权限，增强释放额外消耗已有电量；普通电能仍可进攻防守。
- 真实碰撞事件触发局部黄旗、VSC、安全车；严重堵塞触发红旗，清理后恢复。
- 安全车实际行驶、车辆实际减速跟随；没有按落后差距集结或赠送距离。
- 红旗采用原地暂停的简化模型，不模拟全部车辆返回维修区；蓝旗要求套圈车辆安全让行。
- 保留双车积分、倒序发车、完整单列计时榜、触控镜头与存档导入导出。
- 进行中的旧比赛保留旧规则和资源；尚未开始的分站使用新规则。
