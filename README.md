# APEX 11 · Race52

激烈的持续近距离弯道攻防中，按一次争夺低概率抽取制动失误或后轮打滑；实际碰撞决定损伤与旗号，失误后有恢复冷却。每站增加一圈暖胎，全部赛车完成后回到各自车位停稳，等待全部落位后五灯发车；暖胎圈不占正赛圈数。保留入弯抢线、一次内线防守、弯中并排与出弯交叉反击。碰撞按每辆车自身的接触部位和法向相对速度计算；轻擦、翼片接触与轮组/传动重撞分别处理。保留连续进出站、并行维修和维修后重新追逐。正常绿旗不按名次或落后时间额外加速。

24条赛道的折角改为更宽、更舒展的大半径圆弧，常规目标半径100米，空间紧的弯道按相邻路段调整；急弯入口与出口同步展开。直道保持笔直，路面维持18—24米，维修区直道、赛车比例、湖泊、绿植、看台与球迷保留。这些为游戏竞赛配置。

默认 20 圈，可选 3—30 圈。11 队 22 车、双车积分、倒序发车、禁止赛中补油、轮胎库存与干地两种配方、按圈数安排基础停靠、按总圈数划分收官阶段均保留。

资金只在各车队中展示，保留本季收入、费用、已付金额和欠款，不展示奖金表或账单列表。五类支出仍为燃油、双车维护、轮胎、损伤维修和车队升级。新版赞助 17 万/队/站，基础双车燃油 4 万、维护 8 万，研发运行维护与成果更新也由已有维护/升级类别支付。投资要预留现金，有欠款时暂停非必要研发。

声音默认关闭，点击观赛控制区“开启声音”后启用；暂停、后台和快速完成时静音。首次打开后可导入旧备份；已开始的旧比赛继续旧计算，尚未开始的分站使用新方案，历史资金不追溯改价。

桌面浏览器可直接打开 index.html；iPhone 建议通过 HTTPS 用 Safari 打开。不同网址存档独立，换设备或网址前请导出备份。

GitHub Pages 从默认分支根目录发布 index.html。更新后请等待部署完成并刷新页面。本轮赛况与追赶优化、长赛检查记录见 RACE52_UPDATE.md。
